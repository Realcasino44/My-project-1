# Mucyo Aime | Personal Portfolio

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## 1. Project structure

```text
mechanical_engineering_portfolio/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
    └── Mucyo_Aime_CV.pdf   (add your own CV here)
```

## 2. Open the website

1. Download and extract the project ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click inside the editor and choose **Open with Live Server** if you have the Live Server extension.
5. If you do not have Live Server, double-click `index.html` to open it in your browser.

## 3. Personalize the website

Before publishing, update these items:

- In `index.html`, replace `your.email@example.com` with your real email address in the contact link.
- In `script.js`, replace `your.email@example.com` in `portfolioEmailAddress` with the same real email address.
- Add your CV as `assets/Mucyo_Aime_CV.pdf`. Keep this exact filename or update the download link in `index.html`.
- Replace the LinkedIn placeholder link in the footer with your actual LinkedIn profile URL.
- Review the project descriptions and dates to ensure they accurately reflect your final information.
- Add project photographs or screenshots if you want to replace the CSS illustrations.

## 4. Contact form note

The contact form uses a `mailto:` link. It opens the visitor's default email application with the message prepared. It does not send messages directly or store submissions. A server-side service is required for direct website submissions.

## 5. Publish the website

You can publish this static website using GitHub Pages, Netlify, or another static website host. Upload the complete project folder, including the `assets` folder.
